## 2026-09-09 — Инициализация репозитория
**Контекст:** пустой репозиторий `akmaltong/kungfuman`, есть ТЗ v1.0.
**Решение:** ТЗ сохранено как `docs/SPEC.md`; заведены `CLAUDE.md`, этот журнал и
скелет структуры из раздела 4.5. Внутреннее имя проекта — `kungfuman-platform`.
**Причина:** раздел 12 спеки прямо предписывает этот порядок.
**Последствия:** дальнейшая работа идёт этапами из Части II, по одному за сессию.

## 2026-09-09 — Каркас Next.js собран вручную
**Контекст:** этап 1, задача 1. Спека предлагает `create-next-app`.
**Решение:** каркас написан файлами вручную (App Router, route-группы
`(public)/(student)/(staff)`, клиенты Supabase, middleware, i18n, домен-стабы),
без интерактивного `create-next-app`.
**Причина:** воспроизводимость и ревьюабельность; интерактивный генератор в
CI/сессии неудобен.
**Последствия:** зависимости фиксированы в `package.json`. React закреплён на
19 RC (совместимая с Next 15.0.3 пара). `lib/types/database.ts` — плейсхолдер до
первой генерации `pnpm db:types` из локального Supabase.

## 2026-09-09 — Разведение по ролям в middleware явными префиксами
**Контекст:** пути route-групп `(student)`/`(staff)` не видны в URL.
**Решение:** в `lib/supabase/middleware.ts` логические зоны заданы явными
списками префиксов (`STAFF_PREFIXES`, `STUDENT_PREFIXES`).
**Причина:** middleware видит финальный URL, а не имя группы.
**Последствия:** при добавлении новых разделов админки/кабинета не забывать
дополнять эти списки.
